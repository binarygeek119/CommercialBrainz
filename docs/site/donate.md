# Donate

CommercialBrainz is a volunteer project. Money, spare YouTube cookies, and your time all help keep the archive online and growing.

Use the buttons on this page for Buy Me a Coffee (domain / cloud VM) and cookie donations. Progress bars show how those funds are tracking.

## Domain

Help cover domain registration and DNS so the site name stays ours year after year. The near-term target is **$13** for the next annual renewal.

When you donate via Buy Me a Coffee, put this exact note in “Say something nice…” so it tags the Domain fund:

`Donation for the CommercialBrainz domain`

## Cloud VM

Donate toward the cloud virtual machine that runs the site — API, workers, database, and storage for hashes and thumbnails. We’re on a free-tier VM today; the next step up is about **$50**, which is the Cloud VM fund goal.

Buy Me a Coffee note for the Cloud VM fund:

`Donation for the CommercialBrainz cloud VM`

## YouTube cookies

YouTube often blocks anonymous scrapers. We use logged-in cookies so yt-dlp can pull metadata and download media for fingerprints. When a cookie jar expires, we move to the next one in the backlog.

Please only donate cookies from a **dummy account**: created just for YouTube login, no payment methods, no personal mail, no identity documents. Submissions are encrypted at rest with a site seed (`COOKIE_ENCRYPTION_SEED`). We will behave and keep them as safe as we can — but you choose what you send.

How to export cookies: [yt-dlp wiki — Exporting YouTube cookies](https://github.com/yt-dlp/yt-dlp/wiki/Extractors#exporting-youtube-cookies)

## Donate time

Not everyone can give money or cookies. Time helps just as much:

- Improve [metadata](/browse) — titles, brands, decades, regions.
- [Vote](/voting) on open edits so good submissions land faster.
- Grow into moderation — help review reports and keep quality high (ask a mod/admin after you have a track record).
- Write or fix documentation for contributors and API users (edit files under `docs/site/` on GitHub).
- Help with coding. Much of the codebase is AI-assisted and needs human audit — and in places, replacement. If you enjoy FastAPI, React, Postgres, or yt-dlp plumbing, we would love a hand. See the [GitHub repo](https://github.com/binarygeek119/CommercialBrainz).
