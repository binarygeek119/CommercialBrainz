# Terms overview

Rules for adding commercials, YouTube links, and metadata to CommercialBrainz. You must read and agree to the current **Submission Terms** version (below) before submitting edits.

## Master links and sub links

A **commercial** is one campaign or spot. It can have one **master link** — the main YouTube upload — plus optional **sub links**, which are additional uploads on the same commercial.

- **Master link** — the primary link for the commercial. It holds the main metadata (title, brand, air date, products, and so on). Popularity votes pick which link is the master link.
- **Sub link** — an extra upload on the same commercial (alternate cut, backup mirror, regional copy, etc.). Sub links inherit metadata from the master link and the commercial; you only fill in what differs for that upload.

If a sub link is really a different commercial, anyone with submit access can propose a **split** so it becomes its own master link. Split proposals stay open for up to **3 months**. They pass early with **20 yes votes**, or after 3 months if yes votes outnumber no votes (at least one yes vote required). Moderators can approve or reject at any time. Full rules are in the Submission Terms sections below.

The numbered Submission Terms (with the agree-to-submit gate) are versioned in the application database, not in this Markdown file, so we can track which version each user accepted.
