# Using CommercialBrainz

A short guide to everyday use of the site — browse, account, vote, and submit.

## Browse without an account

Anyone can:

- [Browse](/browse) recent commercials and linked YouTube uploads
- Open a [commercial](/commercials), [brand](/brands), store, service, event, or holiday page
- [Search](/search) by title, brand, tag, and related fields
- Read open [edits](/edits) and the [About](/about) / [Help](/help) docs

You do **not** need an account to look things up or to use the [public API](/help/api).

## Create an account

1. [Register](/register) with a username, email, and password.
2. [Verify your email](/verify-email/pending) — required before you can vote or submit.
3. New accounts start as **vote-only**: you can vote once eligible, but submitting is locked until you pass the submission quiz.

## Vote on submissions

Community edits stay open for review on [Vote](/voting).

Typical rules (see live UI / config if numbers change):

- Edits stay open about **14 days** unless resolved earlier.
- Early close: enough unanimous yes or no votes can finish an edit sooner.
- Mods and admins can apply or reject immediately.
- Full voting power usually requires **account age ≥ 14 days** and **≥ 10 accepted edits** (mods/admins are exempt).

Voting on good work earns **reputation points**, which unlock more concurrent submit slots over time.

## Unlock submitting

1. Read the [Terms of Submission](/terms).
2. Open [Unlock Submit](/submit/upgrade) and pass the short quiz.
3. Use [Submit](/submit) to add a new commercial link or improve metadata.

Start with clear YouTube uploads, accurate brand/title/year, and a short note for voters. Prefer linking alternate cuts as **sub links** on the same commercial when they are the same spot — see [Terms overview](/terms).

## Reputation and submit slots

- Approvals and helpful votes award small reputation increments (on the order of **0.25** points per qualifying event).
- More reputation → more concurrent open submit slots (base slot plus extras as you earn points, up to a site maximum).

## Bulk submit (power users)

Accounts with enough reputation (about **500+** points) or mod/admin role can unlock [Bulk submit](/submit/bulk) after accepting Power User terms. Use this for playlists and large batches — not for everyday single links.

## Report problems

- Wrong or missing metadata → prefer submitting an edit when you can.
- Broken / abusive content → use the report controls on the page when available.
- Copyright takedown → [DMCA](/dmca).
- Bugs / feature ideas → [GitHub Issues](https://github.com/binarygeek119/CommercialBrainz/issues/new/choose).
- Chat → [Discord](https://discord.gg/AEhVjqX4Af).
